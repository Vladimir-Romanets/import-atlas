Every file is one node, however many places import it. Click a node to select it and open what it imports — what it reaches lights up, including which of a barrel's re-exports it actually uses. Click it again to step up to the nearest file importing it, and again to keep walking back. Where a file has importers that aren't on screen, the number on its left draws them; the chevron on its right closes it again. Drag to pan, scroll to zoom. A dashed border (faded, zoomed far out) means every path to the file goes through a type-only import, so nothing here asks it for anything but types.
